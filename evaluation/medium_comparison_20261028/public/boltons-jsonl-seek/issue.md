# Repair JSONLIterator relative seeking and end-of-stream boundaries

JSONLIterator documents rel_seek=0.0 as the beginning and 1.0 as the end. Relative seeking in binary streams currently mixes text and bytes, an explicit 1.0 is rejected, negative relative fractions seek past the end, and aligning a cursor beyond the last newline can loop forever.

Support -1.0 < rel_seek <= 1.0, with a negative fraction interpreted relative to the end (for example -0.25 is the same position as 0.75). Reject values outside that range. For intermediate positions retain the existing alignment rule: align to the first newline at or after the calculated target, or EOF if none remains. Use the stream's text/bytes newline type. Forward iteration starts after that separator; binary reverse iteration includes the preceding complete line. Preserve omitted-rel_seek forward iteration from the caller's current cursor, reverse's default end positioning, ignore_errors, and stream ownership. This task covers seekable in-memory text/binary streams and binary files; general Unicode text-file byte-cookie seeking and unrelated reverse_iter_lines encoding changes are outside scope. Change only existing implementation files.
