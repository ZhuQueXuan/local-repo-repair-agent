# 空购物车修复教学任务

这是一道自建教学题，不是 SWE-bench 任务，也不代表真实仓库难度。

任务：修复空购物车计算总价时报错的问题，保持已有正常输入的结果。

`cart.py` 刻意保留错误版本，`test_cart.py` 提供五项检查。运行 `python -m unittest -v` 时，空输入应报错，其他四项应通过。Agent 在 `temp/` 中的副本上工作，正式任务原始文件保持不变。

首轮仅使用上游固定动作模型验证控制循环。修复步骤由脚本预先提供，因此测试通过不能证明语言模型自行理解并解决了任务。

本任务的中间文件放在本目录 `temp/`；跨项目启动检查和一次性运行脚本放在主项目根 `temp/`。
