## 直接使用

在本文件所在目录双击 **`启动任务面板.cmd`**。它使用已有的`.venv`后台启动服务，并打开[任务面板](http://127.0.0.1:8765/)。本机最终启动入口已实际检查；打开页面不会调用模型。

1. 先选择“离线补丁重放”，在两个已有案例中选题，点击启动。它把归档补丁应用到新副本后重新验收，不会调用模型，也不是一次新的模型修复。
2. 在“运行与历史”中选择记录，查看流程、Agent结束原因和独立验收；点击`repair.diff`查看补丁，点击验证报告查看检查范围。
3. 需要模型实际修复时，切换“真实Agent运行”，选择固定题与策略后启动。原版适配为界面初始策略；上下文、检索仍是显式可选项。所有调用沿用项目共享账本、平台路由和运行保护。
4. 点击“取消任务”后，已开始的请求/命令先受控收尾，不再启动下一动作；已有用量保留。关闭页面不会取消任务。
5. 没有未结束任务时，可点击右上角“停止面板服务”。下次双击启动入口即可重新打开，历史结果仍在。

历史与运行元数据存放在`data/task_service/`，新正式成果位于其`runs/<run_id>/`；工作副本、过程日志继续放temp。程序已读取33条历史任务结果，首道旧格式任务保留为只读历史；新启动支持另外八道固定任务。
