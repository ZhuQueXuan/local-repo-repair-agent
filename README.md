# 用户代码分析 · 本机工作台

当前为 **v1.2.0-rc1候选版**。上传代码文件/ZIP或公开GitHub链接后，可选择分析者出初稿，再由另一会话自行读代码逐条复核；支持、不支持和待验证会分别保留。修复仍由用户另外启动，没有任意仓库自动修复入口。

**独立复核尚未通过真实验收。** 三个具体批准的真实任务均未完成复核，最后一次被无进展保护提前停止；默认保留已验证的仅分析，候选复核需显式选择，可能只留下初稿。当前不能将其作为已验收的正式能力。完整正负记录见[73](Project/73_实现与验收_用户代码分析后的独立复核.md)；v1.1.0单分析及旧发布包见[72](Project/72_实现与验收_用户代码导入与只读分析.md)，原规划见[71](Project/71_规划_用户代码导入与只读分析及双Agent能力说明.md)。

报告中的文件位置和原始片段由程序核对，问题判断由模型生成，可能误报。两次真实任务完成不代表分析准确率通过；公开仓库样例中包含改进建议和证据不足的判断，详见72。

## 直接使用

1. 在当前电脑双击 **启动任务面板.cmd**，打开[本机面板](http://127.0.0.1:8765/)。打开页面不创建任务、不调用模型。
2. 选择一个代码文件或项目ZIP，点击**导入文件 / ZIP**；也可填写**公开GitHub仓库链接**并获取。先准备本机快照，不运行源码、不调用模型。文件夹请先压缩为ZIP；私有仓库请通过不含凭据的ZIP导入。
3. 检查文件清单与排除原因，取消不需要的文件，填写关注问题。允许范围之外的文件不会供模型读取。默认排除.env、疑似凭据、依赖、运行数据等，但自动识别不能覆盖所有敏感内容，请自己检查范围。
4. 默认**仅分析**，最多300秒。候选复核可显式选择，随后增加一个最多180秒的新会话，总计最多480秒，会增加模型用量；双方只读。确认模型外发说明后点击**开始只读分析 · 调用模型**，继续北邮优先/原规则转DeepSeek备用、共享费用记录，不按结果自动重跑。
5. 报告显示结构、流程、候选问题、原文位置与未知；候选复核完成才显示逐条核对和最终报告。失败/取消时保留draft-report初稿与合法部分记录，明确未完成；不能把它当作复核通过。原文件在 `data/task_service/runs/运行ID/`，源码快照在 `data/task_service/sources/来源ID/`，导入后不修改原项目。
6. 取消后等待当前动作收尾；面板守护会在取消等待超过50秒时停止它拥有的执行器，未知费用保留。关闭网页不取消任务。先等待/取消任务，再点**停止面板服务**；下次双击即可重开历史。

启动失败会给出提示和日志位置。若8765端口已有旧版面板，先在旧页面结束任务、停止服务，再双击；启动器不会擅自结束已有进程。强制关闭后台管理进程会失去额外等待守护，重开后也不会自动重发旧请求。

当前浏览器自动化扩展未开启本地文件访问，因此自动上传操作未完成；普通用户手动选择文件不依赖自动化扩展。文件上传接口与ZIP处理已实际验证。浏览器下载未获得自动完成确认，完整HTTP下载与本机文件读取已核对。若下载不便，可直接从上述目录取报告。

## 单、双、三个Agent的区别

首页默认一个只读分析Agent，另有**分析＋独立复核候选**。复核者是相同模型路由下的新会话，必须自己读取源码；初稿和复核结论分开保留，不保证模型误差独立。两角色都没有Bash、写代码、安装依赖或执行测试工具。当前A3工程已接通，真实语言复核仍未跑通。

顶部**演示与修复实验**入口保留现有三种选择：单Agent、双Agent（修复＋只读审查）、三角色（文档查阅＋修复＋审查）。这些角色顺序交接，审查请求修改时最多返工一次；仍针对已登记固定题目。三角色原来就存在，并未在v1.1.0删成两个。角色增加不代表质量一定提升，历史正负结果均保留。

## 功能范围

| 能力 | 当前支持 | 边界 |
| --- | --- | --- |
| 用户工程导入 | 单个代码文件、ZIP、公开GitHub仓库固定commit | UTF-8文字；上传≤20MiB、解压声明总量≤100MiB、≤1000可分析文件/8MiB、单文件≤256KiB；过长路径排除 |
| 只读分析报告 | 精确引文、结构/流程、候选问题、未知/覆盖、历史与费用 | 单分析角色；不运行测试、不安装依赖、不修改代码，不保证通读全仓或缺陷正确 |
| 独立会话复核（候选） | 冻结初稿、逐条支持/不支持/待验证、自己读代码取依据、失败保留 | 真实复核未完成，不保证降低误报；默认关闭，用户显式选择 |
| 创建、排队、取消、结果保存 | 本机串行执行、独立任务副本、只读历史 | 固定登记任务；失败不自动重跑 |
| 单 Agent | 原版适配、上下文与任务状态、按变化发送代码检索 | 默认原版；实验策略不保证改善 |
| 双/三角色 | 文档查阅、修复、只读审查、最多一次返工 | 串行程序编排；额外收益未证明 |
| 任务卡 | 新建真实任务，人工维护计划/补充要求 | 模型收到不等于已遵循，人工完成不等于验收通过 |
| 暂停/续做 | 开任务卡并允许暂停的普通双/三角色 | 整个角色结束后暂停；新关联身份、剩余时限；代码变化拒绝旧暂停点 |
| 工具、Skills、MCP | 普通双/三角色显式开启 | 两份方法包、固定本机只读工具；不支持任意外部MCP |
| 模型 | 原北邮优先 / DeepSeek官方备用，共享用量 | 每请求每平台最多一次，任务内保持备用；Claude只有离线格式候选 |
| 执行环境 | 当前 Windows、项目 Python、Git Bash | 本机执行，没有OS沙箱；不开放不可信任意仓库 |

S+自查和人工缺陷诊断保留实验标识。新导入入口能按文字阅读多种语言，不代表具有每种语言的语法/运行验证能力。私有仓库账户接入、其他托管平台、子模块/LFS自动获取、任意仓库修复、分析后追问、空白电脑安装与跨版本恢复暂未实现。上传原始字节只对纳入快照的文件保留，原ZIP仅记哈希，不保留被排除的敏感正文。
