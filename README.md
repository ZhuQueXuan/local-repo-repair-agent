# 用户代码分析 · 本机工作台

**v1.3.0 正式版**。上传代码或公开仓库链接，先获得带代码依据的分析与独立复核；你另行启动修复后，程序自动安排修改、实际运行检查和再次复核，最后交给你验收。

已用公开 [inflection](https://github.com/jpvanhal/inflection) 的固定历史版本跑通真实完整流程：一轮修改解决两个公开问题，原450项测试和模型预先固定的8项检查全部通过；下载最终副本后，另外一组预留8项连同原测试再跑，458项全部通过。分析、修改和核对使用真实模型，运行检查使用实际Docker。详细结果、失败过程和费用范围见[82验收记录](Project/82_真实验收与发布_公开inflection项目完整流程.md)，可下载[本次修好的公开项目](experiments/public_project_acceptance_20261031/candidate-fixed.zip)。

本次是已知历史问题的工程验收，证明这个小项目的完整流程可用。复杂依赖、大型仓库、分析准确率和多Agent相对收益仍需另外验证。资料助手已接入按需调用，本次未调用它，不能将其真实质量算作通过。

## 直接使用

1. 双击 **启动任务面板.cmd**，打开[本机面板](http://127.0.0.1:8765/)。打开页面不会调用模型。
2. 选择代码文件或项目ZIP，点击**导入文件 / ZIP**；也可填写公开GitHub链接并获取。程序固定具体版本，先在本机准备快照。文件夹请先压缩；私有仓库可上传不含凭据的ZIP。
3. 检查文件清单和排除原因，取消无关文件，填写关注问题。需要第二个角色核对时选择**分析＋独立复核**，确认后开始分析。默认仅分析；分析不会执行或修改源码。
4. 报告生成后，填写一个整体修复目标，例如“除数为零时给出明确错误，正常计算保持正确”，无需逐条挑技术问题。点击**检查运行环境**；修复需要本机Docker已打开及官方检查镜像，缺少镜像时可点**准备运行环境**。程序不会替你重启其他项目服务。
5. 确认修改副本、模型处理和隔离运行后启动修复。程序固定完成条件，再安排修改、运行检查、独立复核；未达到目标就进入下一轮。各轮代码ZIP、修改对照和报告都可以下载，原项目不会被覆盖。
6. 结果显示“待你最终验收”后，查看报告和修改对照，下载副本自行验收。失败、取消或到边界也保留已有成果和剩余问题。关闭网页不会取消任务；先等待或取消任务，再点**停止面板服务**，以后双击重开历史。

启动失败会提示日志位置。8765已有旧版服务时，先在旧页面结束任务、停止服务再启动；启动器不会擅自结束已有进程。启动与依赖说明见[GITHUB_SETUP](GITHUB_SETUP.md)。本机修复结果位于 `data/task_service/runs/运行ID/`，原始快照位于 `data/task_service/sources/来源ID/`。

## 协作和停止边界

一个角色分析，另一个逐条核对问题及代码依据。修改阶段，一个角色修改，另一个结合实际代码、冻结检查和运行结果核对。遇到资料问题时，这些角色可以请资料助手查所选项目说明，或在你启用后查公开官方资料；资料保留出处和不确定性。

达到目标且运行检查、独立复核都满足条件，就交你验收。最多3轮，修复累计15分钟，连续2轮没有实质改善提前停止。修改者连续8个动作没有新进展时，程序停止其空转；已有实际修改则接手检查当前副本，核对通过后才交付。取消、完整性失败或平台异常仍按规则停止。模型调用总次数和固定费用不作为截断条件，用量与未知费用继续记录。

分析最多5分钟，逐条复核共用最多3分钟，合计8分钟。资料单问题最多45秒、同一任务累计90秒，均计入父任务期限。各角色沿用原北邮优先、失败转DeepSeek官方的路由和共享账本。独立会话不等于不同模型，也不保证错误互相独立。

## 当前范围

| 能力 | 支持与边界 |
| --- | --- |
| 导入 | 单文件、ZIP、公开GitHub固定commit；UTF-8文字。上传≤20MiB，解压声明总量≤100MiB，可分析≤1000文件/8MiB，单文件≤256KiB；依赖、隐藏凭据和运行数据等默认排除，仍需自行检查范围。 |
| 分析与复核 | 带文件位置及程序核对的原始片段、未知与覆盖说明；逐条新上下文核对，保留部分结果。模型判断可能误报，不声明通读全仓或准确率通过。 |
| 修复 | 只在所选代码副本修改，原测试和预先冻结的验收不可修改；保留各轮ZIP、diff、实际检查与复核。 |
| 运行检查 | Python3.10的pytest/unittest、Node22内置测试；本机官方镜像按摘要绑定，无网络、无主机挂载、不带模型凭据。项目额外依赖不会自动安装。 |
| 按需资料 | 项目资料、可选公开官方技术资料及论文摘要/HTML；保留原文、来源、日期和哈希。PDF正文未接入，搜索摘要不算正文证据。真实模型质量尚未单独验收。 |
| 历史和取消 | 本机串行执行，失败不自动重发。中断身份不会自动续费；已有成果、用量和未知占位保留。 |
| 原修复实验 | 顶部“演示与修复实验”保留固定题的单Agent、双角色、三角色、任务卡、暂停续做及只读工具实验。其历史结果和边界不因本次发布改变。 |

目前适合先选小项目或明确模块。较大范围可能达到材料窗口或总期限，需要缩小选择；导入容量不等于一次完整分析容量。TypeScript等其他语言可按文字分析，完整运行验收、额外依赖安装、私有仓库账号接入、其他托管平台、子模块/LFS自动获取和空白电脑安装验收尚未完成。

文件上传接口、快照及HTTP下载已经实际验证；浏览器自动文件选择器受本机自动化权限限制，没有据此宣称自动上传UI验收通过。正常使用请手动选文件；也可直接从本机运行目录取报告和ZIP。
