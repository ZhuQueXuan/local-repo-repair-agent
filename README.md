# 本地仓库修复 Agent

基于固定版本 Mini SWE Agent 的本机工程项目。在已登记的 Python 任务上创建独立副本，由 Agent 查阅、修改，再由程序独立检查和重放补丁。v1.0.0 发布验收记录见[70：整体审查与发布](Project/70_审查与发布_本机工程首版.md)。本机工程首版已完成范围内验收，产物与限制见该记录及 releases/v1.0.0_20261030/manifest.json。

## 直接使用

1. 在当前电脑双击 **启动任务面板.cmd**，打开[本机面板](http://127.0.0.1:8765/)。打开页面不创建任务、不调用模型。
2. 默认是**离线补丁重放**。保留“boltons · 大容器排序”或选择“Click · 自定义命令注册”，点击创建；程序在新副本应用已有补丁并验收，不代表模型重新完成了修复。
3. 需要模型修复时，主动切换**真实 Agent 运行**，选择固定题目。默认单 Agent、原版适配；其他策略和多角色用于实验，费用沿用原路由和共享账本。
4. 分别查看**执行流程、Agent结束原因、独立修复验收**。已结束不等于修复通过；部分补丁通过也不代表协作完整成功。
5. 点击成果名称查看预览，再用**完整下载所选成果**取回原始文件。补丁和报告也保存在 `data/task_service/runs/运行ID/`。补丁由你核对后应用，面板不会改你的其他仓库。
6. 取消后等待当前动作收尾；面板守护会在取消等待超过50秒时停止它拥有的执行器，未知费用保留。关闭网页不取消任务。先等待/取消任务，再点**停止面板服务**；下次双击即可重开历史。

启动失败会给出提示和日志位置。若8765端口已有旧版面板，先在旧页面结束任务、停止服务，再双击；启动器不会擅自结束已有进程。强制关闭后台管理进程会失去额外等待守护，重开后也不会自动重发旧请求。

## 功能范围

| 能力 | 当前支持 | 边界 |
| --- | --- | --- |
| 创建、排队、取消、结果保存 | 本机串行执行、独立任务副本、只读历史 | 固定登记任务；失败不自动重跑 |
| 单 Agent | 原版适配、上下文与任务状态、按变化发送代码检索 | 默认原版；实验策略不保证改善 |
| 双/三角色 | 文档查阅、修复、只读审查、最多一次返工 | 串行程序编排；额外收益未证明 |
| 任务卡 | 新建真实任务，人工维护计划/补充要求 | 模型收到不等于已遵循，人工完成不等于验收通过 |
| 暂停/续做 | 开任务卡并允许暂停的普通双/三角色 | 整个角色结束后暂停；新关联身份、剩余时限；代码变化拒绝旧暂停点 |
| 工具、Skills、MCP | 普通双/三角色显式开启 | 两份方法包、固定本机只读工具；不支持任意外部MCP |
| 模型 | 原北邮优先 / DeepSeek官方备用，共享用量 | 每请求每平台最多一次，任务内保持备用；Claude只有离线格式候选 |
| 执行环境 | 当前 Windows、项目 Python、Git Bash | 本机执行，没有OS沙箱；不开放不可信任意仓库 |

S+自查和人工缺陷诊断保留实验标识。Node环境探测不代表通用JS/TS任务服务。空白电脑安装、其他系统、任意仓库导入、跨版本恢复均不在首版范围。

## 验证与开发入口

使用流程、源码依据、历史正负结果和本轮实际验收见[70](Project/70_审查与发布_本机工程首版.md)。本机工程可用与多 Agent 的解题收益是两项结论；没有官方 SWE-bench 成绩或通用成功率声明。

```powershell
# 默认离线回归：上游原样适用子集与本项目扩展分开报告
.venv\Scripts\python.exe -B scripts/run_regression.py
# 执行环境适配；保留并逐名对照六项既有环境/路径差异
.venv\Scripts\python.exe -B scripts/run_regression.py --scope upstream --upstream-profile adapter
# 无真实模型的三角色预设回复演示，实际执行本机检查/补丁重放
.venv\Scripts\python.exe -B scripts/document_agent_demo.py
```

从源码重新准备环境见[GITHUB_SETUP.md](GITHUB_SETUP.md)；该指南没有空白电脑实测背书。上游固定2.4.6、提交 `04d809ceab9df28f9adaed044884180159172930`，来源与许可见[THIRD_PARTY.md](THIRD_PARTY.md)。本轮不升级底座或新增依赖。

私有凭据只放 `.env`，实时任务和累计账本在 `data/`，不随源码上传。临时过程在 `temp/`，历史实验在 `experiments/`，旧失败、评分和费用不回填。当前状态入口：[00快速接手](Project/00_项目现状与快速接手.md)；开发经过：[项目开发流水账](Project/项目开发流水账.md)。
