# 本地仓库修复 Agent

基于固定版本 Mini SWE Agent 的本机工程项目：在已登记的 Python 仓库题目上，完成查阅、修复、审查、独立验收和结果留存，并逐步增加 Harness 能力。

当前为开发原型。一次已知题的真实三角色接入已通过，六题同题比较暴露出文档查阅与审查的稳定性问题；没有官方 SWE-bench 成绩或稳定效果提升结论。异机安装验证已按用户要求取消。

## 从这里开始

- 已在原电脑：双击 `启动任务面板.cmd`，打开[本机面板](http://127.0.0.1:8765/)。打开页面不会创建任务或调用模型。
- 从 GitHub 下载：[私有仓库](https://github.com/ZhuQueXuan/local-repo-repair-agent)，按 [GITHUB_SETUP.md](GITHUB_SETUP.md) 递归获取子模块、建立环境和配置本机凭据。空白机器安装仍未验收。
- 查看当前状态：[快速接手](Project/00_项目现状与快速接手.md)；查看统一使用/验收范围：[阶段42](Project/42_过程_统一使用入口与整体验收范围.md)。

## 一条完整使用流程

1. **先看环境。** 点击“检查执行环境”，查看 Bash、当前 Python、Node、Git 的路径与版本。它只运行固定版本命令，不安装依赖或调用模型；Node 可用不等于任务服务支持 JavaScript。
2. **先用离线模式熟悉面板。** 默认“离线补丁重放”，支持已有 Click 命令注册和 boltons 排序案例，把历史补丁应用到新副本再验收；不产生新模型修复成绩。
3. **需要实际修复时再切真实运行。** 选择已登记题目、策略和单/双/三角色。多角色当前使用“上下文与任务状态”策略；三角色需填写明确的文档问题。创建会调用原模型路由并累计用量。
4. **按需开启 Harness 功能。** 任务卡、阶段暂停、工具/Skills 开关默认都关闭，组合范围见下表。模型配置目前只开放原“北邮优先 / DeepSeek备用”。
5. **分别看流程、修复与审查结果。** 查阅引用和未知、候选版本、程序检查/补丁重放、审查意见、角色用量与费用。计划状态和模型自报不能替代程序验收；修复通过而协作失败时两者分别保留。
6. **有需要再暂停或取消。** 暂停等待完整角色结束；继续创建唯一关联新任务，保留原身份、剩余时间、环境/模型绑定和费用。取消/失败/进程中断不自动重发；关闭页面不会取消任务。

## 功能与可用组合

| 功能 | 当前范围 | 关键边界 |
| --- | --- | --- |
| 单 Agent 修复 | 已登记 Python 题目与原版/上下文/检索策略 | 当前适配不等同于最初冻结 baseline；正式比较需要新冻结 |
| 双角色 | 修复 → 独立首审 → 必要返工一次 → 最终核查 | 合法批准可提前结束；不强迫返工或循环直到成功 |
| 三角色 | 前置只读文档查阅，再进入双角色流程 | 创建时给一个问题；不是通用动态委派或并行团队 |
| 任务卡 | 新建真实单/多角色，可维护目标、步骤、阻塞和补充要求 | 人工计划状态不是程序验收；旧记录不补造 |
| 阶段暂停/续做 | 开任务卡的新建普通双/三角色 | 整个角色边界，独立新身份；单Agent/S+/诊断暂不支持 |
| 工具 / Skills / MCP | 新建普通双/三角色，显式开启 | 两份按需方法包、固定本机只读变更概览；不扩大权限或伪造证据 |
| 执行环境 | Windows 本机 Git Bash 与显式 argv 后端 | 没有 OS 沙箱，不保证不可信程序隔离；Node 仅声明/开发夹具 |
| 模型能力配置 | 原北邮优先 / DeepSeek备用，共享路由与账本 | Claude Messages 只有离线格式候选，无联网客户端，页面/API均不能创建运行 |

S+同一 Agent 自查和人工种子诊断保留为已有实验分支，暂停/工具扩展不覆盖它们，也不作为当前单Agent与完整多Agent比较的前置。

## 数据、来源与开发入口

本机实时任务、用量与共享账本在 `data/`，私有凭据在 `.env`；它们不随 GitHub 上传。`temp/` 存过程材料，`experiments/` 存正式留证；远端只包含声明范围的材料，五份封存包仍留本机，详见安装说明。不要重置账本、覆盖旧失败、改旧freeze哈希或自动恢复旧身份。

上游固定 Mini SWE Agent 2.4.6，commit `04d809ceab9df28f9adaed044884180159172930`。本项目增加本机适配、共享记账/路由、上下文/任务状态、代码检索、多角色权限与证据、任务面板和 Harness 模块；上游与题目源码来源见 [THIRD_PARTY.md](THIRD_PARTY.md)。

```powershell
# 无外部模型的三角色预设回复演示；实际写临时副本并做本机验收
.venv\Scripts\python.exe -B scripts/document_agent_demo.py

# 仅读取环境声明；加 --probe 才执行固定版本命令
.venv\Scripts\python.exe -B scripts/execution_runtime.py

# 集中工程检查入口；适配仍保留六项已知环境/路径差异
.venv\Scripts\python.exe -B scripts/run_regression.py
.venv\Scripts\python.exe -B scripts/run_regression.py --scope upstream --upstream-profile adapter
```
