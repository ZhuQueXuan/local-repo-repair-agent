The base `__reduce__` returns `(cls, (msg, doc, pos))`. The problem: requests' `__init__` calls `InvalidJSONError.__init__(self, *self.args)` where `self.args` is the single formatted message. So `self.args` becomes `(formatted_msg,)`, and `__reduce__` returns `(cls, (formatted_msg,))` — only one arg.
