done
360             created in the same directory as the destination path.
361         overwrite_part (bool): Whether to overwrite the *part_file*,
362             should it exist at setup time. Defaults to ``False``,
363             which results in an :exc:`OSError` being raised on
364             pre-existing part files. Be careful of setting this to
365             ``True`` in situations when multiple threads or processes
366             could be writing to the same part file.
367         rm_part_on_exc (bool): Remove *part_file* on exception cases.
368             Defaults to ``True``, but ``False`` can be useful for
369             recovery in some cases. Note that resumption is not
370             automatic and by default an :exc:`OSError` is raised if
371             the *part_file* exists.
372 
373     Practically, the AtomicSaver serves a few purposes:
374 
375       * Avoiding overwriting an existing, valid file with a partially
376         written one.
377       * Providing a reasonable guarantee that a part file only has one
378         writer at a time.
379       * Optional recovery of partial data in failure cases.
380

382     .. _umask: https://en.wikipedia.org/wiki/Umask
