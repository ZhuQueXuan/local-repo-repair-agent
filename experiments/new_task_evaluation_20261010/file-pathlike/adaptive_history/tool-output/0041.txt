492 'def iter_find_files(directory, patterns, ignored=None, include_dirs=False, max_depth=None):'
493 '    """Returns a generator that yields file paths under a *directory*,'
494 '    matching *patterns* using `glob`_ syntax (e.g., ``*.txt``). Also'
495 '    supports *ignored* patterns.'
496 ''
497 '    Args:'
498 '        directory (str): Path that serves as the root of the'
499 '            search. Yielded paths will include this as a prefix.'
500 '        patterns (str or list): A single pattern or list of'
501 '            glob-formatted patterns to find under *directory*.'
502 '        ignored (str or list): A single pattern or list of'
503 '            glob-formatted patterns to ignore.'
504 '        include_dirs (bool): Whether to include directories that match'
505 '           patterns, as well. Defaults to ``False``.'
506 '        max_depth (int): traverse up to this level of subdirectory.'
507 '           I.e., 0 for the specified *directory* only, 1 for *directory* '
508 '           and one level of subdirectory.'
509 ''
510 '    For example, finding Python files in the current directory:'
511 ''
512 '    >>> _CUR_DIR = os.path.dirname(os.path.abspath(__file__))'
513 "    >>> filenames = sorted(iter_find_files(_CUR_DIR, '*.py'))"
514 '    >>> os.path.basename(filenames[-1])'
515 "    'urlutils.py'"
516 ''
517 '    Or, Python files while ignoring emacs lockfiles:'
518 ''
519 "    >>> filenames = iter_find_files(_CUR_DIR, '*.py', ignored='.#*')"
520 ''
521 '    .. _glob: https://en.wikipedia.org/wiki/Glob_%28programming%29'
